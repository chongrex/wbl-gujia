# 万宝楼估价助手

一个 Chrome 浏览器插件，在万宝楼（剑网3）角色页面自动获取商品编号，调用爱剑三估价接口自动出估价结果，并支持临时保存、对比列表和收藏列表。

## 功能

- **自动获取编号**：在万宝楼角色详情弹窗打开时，自动识别并提取「商品编号：xxx」。
- **免点详情获取列表**：无需点开每个角色详情，点击「获取当前列表」即可直接从万宝楼列表接口拉取当前页所有在售角色（编号、角色名、区服、门派、价格），每个角色旁附「估价」按钮。
- **筛选条件同步**：插件会捕获页面发起的列表请求参数，「获取当前列表」时精确复用你在页面上选择的筛选条件（门派、体型、服务器、价格、排序等），返回结果与页面显示一致。
- **原生卡片注入按钮**：自动在每个角色卡片上注入「估价」「收藏」「对比」三个按钮，无需点详情即可一键估价、收藏或加入对比。
- **悬浮面板可拖拽**：按住面板标题栏即可拖拽移动到任意位置。
- **一键估价**：自动调用爱剑三估价流程（编号 → 搜索 → 立即估价），在插件悬浮面板中直接展示估价结果（估价价格、门派/体型、资历、金发/红发/白发、穿过的海景房等）。
- **弹窗四个 Tab 分开展示**：点击工具栏插件图标打开弹窗，分为「估价列表」「估价结果」「收藏列表」「对比列表」四个页签，各司其职、互不干扰。
  - 估价列表：展示万宝楼当前获取的角色列表，可一键估价/收藏/对比。
  - 估价结果：自动保存每次估价结果，可查看、打开、收藏、对比。
  - 收藏列表：收藏的账号。
  - 对比列表：加入对比的账号。
- **对比列表**：将多个估价结果加入对比列表，方便横向比较。
- **收藏列表**：收藏心仪的账号估价结果。

## 安装

1. 打开 Chrome，访问 `chrome://extensions/`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目目录（`wbl-gujia`）。

## 使用

1. 打开万宝楼角色页面：<https://jx3.seasunwbl.com/buyer?t=role>。
2. 页面右侧会出现「估价助手」悬浮面板。
3. 有两种方式获取编号：
   - **免点详情（推荐）**：先在页面上设置好筛选条件并点「查询」，再点击面板中的「获取当前列表」，插件会拉取与你筛选结果一致的角色列表，点击角色旁的「估价」按钮即可。
   - **详情弹窗**：点击任意角色的「详情」打开详情弹窗，插件自动提取商品编号。
   - 也可在面板输入框中手动粘贴/输入 18-20 位商品编号。
4. 点击「立即估价」，等待片刻即可看到估价结果。
5. 估价完成后，可点击「临时保存」「加入对比」「加入收藏」。
6. 点击浏览器工具栏中的插件图标，打开弹窗查看对比列表和收藏列表。

## 重要说明

- **估价需要登录爱剑三账号**：爱剑三的估价接口要求登录态（`open-token` cookie）。
  首次使用前，请先在浏览器中登录爱剑三：<https://www.aijx3.cn/>（或点击插件面板中的「点击登录爱剑三」链接）。
  登录后，插件会自动携带登录态进行估价。
- **查看详情需要登录万宝楼**：万宝楼的角色详情弹窗需要登录后才能查看商品编号。
- 商品编号为 18-20 位数字，例如 `1404068307854450688`。

## 技术实现

- **Manifest V3**，使用 `background` service worker 处理跨域请求和存储。
- 估价流程复用了爱剑三官网的接口：
  - 万宝楼角色列表：`GET https://trade-api.seasunwbl.com/api/buyer/goods/list`（无需登录，`consignment_id` 即商品编号）
  - 编号 → 账号ID：`GET https://www.aijx3.cn/api2/web/getZhanghaoResultWbl3`（参数 `accoSeq`）
  - 估价：`POST https://www.aijx3.cn/api2/web/dispath`（`method=guji.compute.account.by.id` + `zhanghaoId` + `valueType`）
- 数据存储使用 `chrome.storage.local`。

## 已知说明

- 爱剑三对新上架账号采用「懒收录」机制：首次搜索会触发后台抓取，可能短暂返回空。插件已内置自动重试（最多 4 次，间隔递增），一般情况下重试后即可正常估价。
